# 0025 — Tuples & Multiple Return

Return both the smaller and larger of `3` and `7` from one function, unpacking the pair to print `min: 3` and `max: 7`. Rust returns a tuple `(i32, i32)` — a fixed-size, heterogeneous, anonymous group — and `let (lo, hi) = ...` destructures it. Tuple fields are also reachable positionally as `.0` and `.1`.

## Run

    cargo run
