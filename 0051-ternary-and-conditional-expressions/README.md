# 0051 — Ternary & Conditional Expressions

For each of `4` and `7`, choose `even` or `odd` with a single conditional expression and print `4: even` and `7: odd`. Rust has no `?:` because `if` is itself an *expression*: `if cond { a } else { b }` evaluates to one of the arms. Both arms must yield the same type.

## Run

    cargo run
