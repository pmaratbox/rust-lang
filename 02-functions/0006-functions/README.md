# 0006 — Functions

Define `add(a, b)` returning their sum, call it with `3` and `4`, and print
the result. Signature form is `fn name(params) -> ReturnType`. The final
expression of a block is its value, so `a + b` (no trailing semicolon, no
`return`) is the idiomatic return — adding a semicolon would make it a
statement and break the return type.

## Run

    cargo run
