# 0002 — Variables & basic types

Declare `let` bindings for Rust's four basic types: a 32-bit int (`i32`),
a 64-bit float (`f64`), a borrowed string slice (`&str`), and a `bool`.
Bindings are immutable by default; type annotations are optional here
(Rust would infer them) but shown to make the types explicit.

## Run

    cargo run
