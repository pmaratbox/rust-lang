# 0003 — Arithmetic & operators

Compute and print the five elementary arithmetic operations on two integers
(`a = 17`, `b = 5`). Rust's `/` between two `i32`s truncates toward zero
(`17 / 5 → 3`); cast to `f64` (`a as f64 / b as f64`) for fractional
division. The compiler will refuse to mix integer and float operands.

## Run

    cargo run
