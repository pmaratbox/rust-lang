# 0046 — Number Bases & Radix

Print the integer `255` in hexadecimal, octal, and binary, producing `hex: ff`, `oct: 377`, and `bin: 11111111`. Formatting traits select the base: `{:x}` for hex, `{:o}` for octal, and `{:b}` for binary, with `{:#x}` adding the `0x` prefix. They work for any integer type.

## Run

    cargo run
